System Architecture

Multi-source satellite + best-track + reanalysis data → six AI models → decision layer → API → single-screen dashboard

1 · Data sources

GridSat-B1 (NOAA)
basin-wide IR + water vapour, 3-hourly, 0.07°
TCIR benchmark
storm-centred IR · WV · microwave, 2003–16
INSAT-3D (MOSDAC/Kaggle)
external test + live-feed slot
IBTrACS (NOAA)
track, wind, pressure 1982–2025
ERA5 SST, shear, humidity · WorldPop population · Natural Earth coast
➜

2 · Preparation

Brightness temp → normalised image, 14° storm crops
Southern-hemisphere storms mirrored to NIO rotation
IBTrACS ↔ image matching by time + position
IMD scale labels (D → SuCS) + Dvorak T-numbers
ADT-lite cloud features (eye, ring, cold cover)
Split by storm & year — no leakage
➜

3 · AI models

Basin detector ResNet-18 heatmap NEW
finds every system in the raw scene
Intensity CNN EfficientNet-B0
wind · Dvorak T · IMD class · Grad-CAM
ConvLSTM 8-frame image sequence
24 h change (experimental RI)
RI early warning LightGBM NEW
P(+30 kt / 24 h), SHAP reasons
Genesis LightGBM NEW · Track LSTM + calibrated cone
